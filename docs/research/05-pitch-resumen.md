# 05 - Resumen ejecutivo, pitch deck y teaser

Sintesis Sequoia + Y Combinator. Verificacion directa: Sequoia guide (fetch 2026-10-11).

## Secciones obligatorias

### A. Teaser / resumen ejecutivo (5-7 slides o 1 pagina, para email)

Portada (nombre + eslogan) -> hook (pregunta o dato) -> problema -> solucion -> mercado (TAM/SAM/SOM) -> traccion -> ask (monto + uso).

### B. Pitch deck Sequoia (10-12 slides)

1. Portada. 2. Proposito (1 frase declarativa). 3. Problema. 4. Solucion. 5. Why now. 6. Mercado. 7. Competencia. 8. Producto. 9. Modelo de negocio. 10. Equipo. 11. Financieros. 12. Vision / ask.

### C. Pitch deck YC (7-10 slides, ultra-conciso)

Portada -> problema -> solucion -> mercado -> traccion -> modelo -> equipo -> ask -> vision/roadmap (opcional).

Teaser = primer contacto; deck completo = reunion 15-20 min / demo day.

## Tablas requeridas

### T1. Slide x contenido x metrica

| Slide | Contenido esencial | Metrica que exige el inversor |
|---|---|---|
| Proposito/hook | 1 frase o estadistica impactante | - |
| Problema | Dolor cuantificado, sin jerga | % sin solucion, costo ineficiencia ($/h) |
| Solucion | Mockup/captura, diferencial | Tiempo adopcion, NPS, % reduccion costo |
| Why now (Sequoia) | Tendencia macro/regulatoria | Evidencia fechada |
| Mercado | TAM/SAM/SOM + ICP | TAM USD, CAGR, N clientes |
| Competencia | Tabla 3-4 + moat | Debilidad vs ventaja |
| Producto/traccion | Roadmap o adopcion | DAU/MAU, MoM >=20%, retencion >=80%, MRR |
| Modelo | Ingresos, precio, unit economics | LTV, CAC, payback, margen bruto >=60% |
| Equipo | 3 fundadores + logro | Anos, exits previos |
| Financieros | P&L 3-5a, burn, runway | Burn, runway, EBITDA |
| Vision/ask | Futuro + monto + valuacion + uso | % producto/mkt/contratacion |

### T2. Sequoia vs YC (cuando usar cada uno)

| Aspecto | Sequoia 10-12 | YC 7-10 |
|---|---|---|
| Longitud | 10-12 + apendice | 7-10 ultra-conciso |
| Orden distintivo | Proposito primero, vision al final | 7 preguntas clasicas |
| Traccion | Acepta vision en seed, exige traccion en Serie A | Exige metricas tempranas siempre |
| Diseno | Minimalista, sans >=24pt titulo, 16:9 PDF/Slides | Idem + "legible y obvio" |
| Uso | Serie A / sectores regulados (fintech, healthtech: anadir Why now + competencia) | Seed / pre-producto |

## Storytelling (6 tecnicas)

1. Hook inmediato (dato o anecdota del dolor).
2. Problema -> solucion -> prueba en cada slide ("por que importa").
3. Datos con fuente confiable + grafico simple.
4. Prueba social (logos piloto, prensa, testimonios).
5. Linea de tiempo MVP -> beta -> ingresos.
6. Cierre con vision ligada a tendencia macro.

## Diseno

Neutros (blanco/gris) + 1-2 acentos; sans legible (Inter/Roboto/Helvetica); barras/lineas simples; iconos sobre stock photos; margenes amplios; logo discreto; 16:9.

## Errores comunes

1. 20+ slides o parrafos (nadie lo lee).
2. Sin why now (parece idea vieja).
3. TAM sin metodologia (numero magico).
4. Sin competencia ("no tenemos competidores" = no hay mercado o no investigaste).
5. Traccion vanidosa (descargas sin retencion/MRR).
6. Ask sin uso de fondos ni valuacion.
7. Tipografia <18pt, fotos stock, voz en off que tapa numeros.

## Checklist

- [ ] <=12 slides, 16:9, PDF/Slides compartible.
- [ ] Cada slide responde "por que importa".
- [ ] TAM/SAM/SOM con fuente en slide + anexo con math.
- [ ] Competencia 3-4 con moat explicito.
- [ ] Traccion con MoM, retencion, MRR (no solo descargas).
- [ ] Modelo con LTV/CAC/payback.
- [ ] Ask con monto, valuacion pre-money y tabla de uso.
- [ ] Contacto en portada y cierre.
