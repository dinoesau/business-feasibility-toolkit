# Checklist - Validacion de mercado

## 1. MVP

- [ ] MVP definido (que incluye y que excluye por escrito).
- [ ] Probado con >=10 usuarios tempranos fuera del circulo familiar.

## 2. Entrevistas y encuestas

- [ ] >=20 entrevistas estructuradas o 100 encuestas con disposicion a pagar medida.
- [ ] Objeciones top 3 documentadas.

## 3. Pruebas A/B

- [ ] Test de precios (al menos 2 niveles).
- [ ] Test de canales (al menos 2) con costo medido.
- [ ] Test de mensajes (al menos 2) con conversion medida.

## 4. Metricas

- [ ] CAC calculado.
- [ ] LTV estimado y ratio LTV/CAC >= 3 (o plan para llegar).
- [ ] Churn y conversion medidos (o proxy declarado si pre-lanzamiento).

## 5. Iteracion y evidencia

- [ ] Decision por metrica: mantener / pivotar / matar, con fecha.
- [ ] Resultados guardados para el data-room (carpeta inversionistas).

**Salida:** proyeccion de ventas defendible para el estudio financiero (misma cifra en plan, resumen y deck).
