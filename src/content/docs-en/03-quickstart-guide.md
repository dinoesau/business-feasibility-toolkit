# 03 - Quickstart guide

> **Legal validity: Mexico only.**

## 5-step path (30 minutes to 4 weeks)

1. **Idea sheet (30-60 min):** complete it. Without a clear value proposition or paying market, iterate or discard.
2. **Pre-feasibility (1-3 days):** apply `checklists/prefactibilidad.md`. If regulatory or technical checks fail, do not start the full study.
3. **Feasibility (2-4 weeks):** build the 6 studies in order market -> technical -> organizational -> MX legal -> financial -> environmental.
4. **Go/No-Go decision (1 session):** apply `checklists/go-no-go.md` with the integral table. Requires >=70% of assumptions confirmed and closed numbers.
5. **Packaging:** business plan -> executive summary -> pitch deck -> founders' agreement. Verify figure consistency across the first three.
